# PyTorch official tutorial snapshot

Offline copy of the official **Learn the Basics** tutorial source from
<https://github.com/pytorch/tutorials>, commit
`4d66ab3f9226b7e712b725f9cf0f03fe5b0f1531`.

Read in this order:

1. `basics/tensorqs_tutorial.py`
2. `basics/data_tutorial.py`
3. `basics/buildmodel_tutorial.py`
4. `basics/autogradqs_tutorial.py`
5. `basics/optimization_tutorial.py`
6. `basics/saveloadrun_tutorial.py`

These are documentation source files, so their comments and reStructuredText markup
are intentional. The upstream license is copied as `LICENSE`. For installation and
platform-specific wheels, use <https://pytorch.org/get-started/locally/>.
