        \subsection{Mathematical statement}


For class label $y_i$ and logits $\bm z_i$, the fused loss is
\[
\begin{aligned}
\ell_i
  &=-\log\frac{e^{z_{i,y_i}}}{\sum_{k=1}^{K}e^{z_{ik}}}\\
  &=\operatorname{LSE}(\bm z_i)-z_{i,y_i},\\
\operatorname{LSE}(\bm z_i)
  &=m_i+\log\sum_{k=1}^{K}e^{z_{ik}-m_i}.
\end{aligned}
\]
The mean reduction is $N^{-1}\sum_i\ell_i$; \code{none} returns the vector.

        \subsection{Theory--engineering gap inventory}

        \begin{gapbox}
        \textbf{Explicit gap.} The negative log-likelihood is one mathematical expression, while an implementation chooses whether to fuse normalization/logarithm, represent targets densely, and define reduction.

        \textbf{Implicit gap exposed by the result.} A true class with rounded softmax probability zero makes \code{-log(p)} infinite, while the logit-domain loss remains finite and informative.
        \end{gapbox}
