        \subsection{Mathematical statement}


For logits $Z$ and sparse labels $y$, the wrapper must return
\[
\begin{gathered}
\bm\ell\in\mathbb R^N,\qquad
\bar\ell=N^{-1}\bm1_N^\top\bm\ell,\\
G=\nabla_Z\bar\ell\in\mathbb R^{N\times K}.
\end{gathered}
\]
The input is raw, unnormalized logits.  Labels are integer class indices.  The
autograd scalar is the mean of the unreduced fused losses.

        \subsection{Theory--engineering gap inventory}

        \begin{gapbox}
        \textbf{Explicit gap.} The symbol cross-entropy does not state whether inputs are logits/probabilities, labels are sparse/dense, reduction is mean/sum/none, or gradients belong to a leaf tensor.

        \textbf{Implicit gap exposed by the result.} Passing already normalized probabilities to a logit-expecting fused loss returns a finite but different answer, so finiteness alone cannot detect API misuse.
        \end{gapbox}

        \subsection{Acceptance evidence}

        \begin{evidencebox}
        \begin{itemize}
          \item Unreduced losses, mean, and gradient agree with a stable SciPy/NumPy oracle on extreme logits.
  \item Returned arrays own their memory and have the requested shape/dtype.
  \item The benchmark prints the double-softmax misuse discrepancy separately from oracle error.
        \end{itemize}
        \end{evidencebox}

        \subsection{Constraints}

        \begin{itemize}
          \item Use CPU float64 and sparse int64 labels; no model, optimizer, DataLoader, or GPU.
  \item Use the official fused PyTorch loss rather than rebuilding it.
  \item Detach and copy before returning NumPy evidence.
        \end{itemize}
