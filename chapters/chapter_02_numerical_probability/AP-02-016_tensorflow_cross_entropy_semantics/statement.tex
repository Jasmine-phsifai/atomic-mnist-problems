        \subsection{Theory--engineering gap inventory}

        \begin{gapbox}
        \textbf{Explicit gap.} Equivalent calculus does not imply identical framework mechanics: TensorFlow uses tape scope/watch semantics and a separate reduction operation around an unreduced fused loss.

        \textbf{Implicit gap exposed by the result.} Feeding probabilities while declaring them logits again produces a finite wrong answer, demonstrating a cross-framework semantic hazard rather than a numerical exception.
        \end{gapbox}

        \subsection{Acceptance evidence}

        \begin{evidencebox}
        \begin{itemize}
          \item Loss vector, mean, and gradient agree with the same stable SciPy/NumPy oracle used for PyTorch.
  \item The tape returns a non-null gradient with matching float64 shape.
  \item The benchmark reports the finite probability-as-logits discrepancy and oracle error separately.
